# ADR 0008 : fondations du frontend

Statut : accepté par Guillaume le 24 octobre 2026 (« React Compiler, ESLint hooks, i18n anglais par défaut, Base UI, AbortController pour ce qui n'est pas une query »). Dépend de DESIGN.md et de `docs/design/`.

## Décisions
- **Outillage** : React Compiler 1.0 via `reactCompilerPreset` de `@vitejs/plugin-react` 6 et `@rolldown/plugin-babel` (react.dev, installation) ; ESLint 10 avec `typescript-eslint` et `eslint-plugin-react-hooks` 7.1.1, preset `recommended`. React.dev mentionne `recommended-latest`, mais le README de la version installée le qualifie d'expérimental : on suit la version installée. Vite passe en 8.3.5 (correctif). TypeScript 7 et Vitest 5 sont sortis, mais leur migration est une décision à part.
- **Langues** : anglais par défaut, français en première traduction. Catalogue source `src/i18n/en.ts` ; `fr.ts` est typé sur ses clés (une clé manquante ou en trop casse la compilation) et un test vérifie les mêmes variables et formes de pluriel. Formatage sans dépendance : variables `{name}`, pluriels par `Intl.PluralRules`, nombres et dates par `Intl` ; une date sans heure est formatée en UTC. Choix gardé dans le navigateur, `<html lang>` mis à jour. Les catalogues restent des données simples, donc migrables vers une bibliothèque i18n si les traducteurs en ont besoin.
- **Requêtes** : les lectures passent par `api.useQuery`. Vérifié dans le code installé : openapi-react-query transmet la `signal` de TanStack à openapi-fetch, et TanStack annule la requête quand plus aucun composant ne l'observe. Les autres requêtes utilisent `useAbortableRequest` : un nouvel appel annule le précédent, le démontage annule la requête en cours, `isAbortError` sépare l'annulation d'une vraie erreur.
- **Composants** : enveloppes fines sur les exports publics de Base UI 1.9.0 dans `src/ui/`, d'après `docs/design/components.md`. Premier lot de composants : Button, TextField, SelectField, ChoiceGroup, Checkbox, Dialog, ConfirmationDialog, Tabs, Disclosure, StatusLabel, InlineMessage, ErrorSummary, EmptyState, PendingState, Pagination, DateRange. Tokens de `docs/design/tokens.css` copiés tels quels, avec un test de parité. Police Raleway auto-hébergée (`@fontsource-variable/raleway`, OFL-1.1), sans requête vers un tiers.
- **Catalogue** : page interne `/dev/components`, chargée seulement en développement et absente du build de production.

## Reste du lot des fondations et suite
Composants du premier lot encore à faire : SearchCombobox, NavigationDrawer, DataTable, FilterBar, FileInput, RecordComparison, ReviewActionBar. Les trois derniers dépendent des API privées de revue (ADR 0009). L'écran public existant passe aux catalogues et aux composants, mais sa refonte reste le lot d’exploration publique.

## Revue indépendante et vérifications
Revue en lecture seule : aucun défaut bloquant. Deux défauts importants corrigés avec tests : le résumé d'erreurs volait le focus à chaque frappe (il ne le prend plus qu'à une nouvelle soumission) ; un échec de confirmation était invisible, le dialogue modal masquant le reste de la page (le message d'échec s'affiche désormais dans le dialogue). Points mineurs corrigés : styles de l'écran public existant conservés (lignes, fiche, pagination), catégorie inconnue affichée sans planter la page, « Inconnu » et « Inconnue » séparés, carte non reconstruite au changement de langue et dégradée sans disparaître sur une erreur non fatale, contexte WebGL de test libéré, erreurs de champ affichées après sortie du champ, validation native désactivée au profit du flux d'erreurs, description d'une option reliée par `aria-describedby`, langue des noms de langue, titre et description de la page traduits, période suivant les changements du parent, boutons de pagination focusables pendant un chargement, textes du catalogue de développement retirés du bundle de production. Limite connue : l'attribution de la carte garde la langue du chargement jusqu'au rechargement.

Vérifié : lint, typecheck, 30 tests frontend, build ; CI locale complète (127 tests backend, migrations, `check --deploy`, OpenAPI et types inchangés, installation figée, test négatif TS) ; navigateur intégré sur le backend local : anglais par défaut, bascule en français au clavier, choix conservé au rechargement, `<html lang>` à jour, police Raleway chargée depuis le bundle, aucun débordement horizontal à 280 px, aucune erreur console, dialogue de confirmation avec focus sur « Annuler », Escape et retour du focus.
